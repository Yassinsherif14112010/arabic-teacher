# الشاعر في اللغة العربية — Flutter App

تطبيق Flutter أوفلاين أول لإدارة طلاب مدرس اللغة العربية أ. محسن شاكر.

## المميزات

- **أوفلاين أول** — جميع البيانات محفوظة محلياً في SQLite، لا يحتاج إلى سيرفر
- **دعم RTL** — واجهة عربية كاملة من اليمين إلى اليسار
- **محسّن للأجهزة اللوحية** — تخطيط sidebar ثابت على الشاشات الكبيرة
- **وضع مظلم/فاتح** — قابل للتبديل من الشريط الجانبي

## الشاشات

| الشاشة | الوصف |
|--------|-------|
| **لوحة التحكم** | إحصائيات سريعة، إدارة المجموعات الدراسية، ملخص الحضور |
| **إدارة الطلاب** | إضافة/تعديل/حذف الطلاب، عرض الباركود، تجميع حسب الصف |
| **تسجيل الحضور** | مسح الباركود، رقم الكشف، تسجيل يدوي لكل طالب |
| **المصروفات** | إعداد رسوم السنة الدراسية، تسجيل الدفعات، تصفية وتقارير |
| **الامتحانات** | تسجيل درجات الامتحانات اليومية/الشهرية/النهائية، إحصائيات الطالب |

## البنية التقنية

```
lib/
├── main.dart              # نقطة الدخول، RTL، الثيم
├── models/                # نماذج البيانات (Student, Attendance, Payment, Grade, ...)
├── services/
│   └── database_service.dart  # SQLite — لا يوجد اتصال بالشبكة
├── providers/
│   ├── app_provider.dart  # إدارة الحالة المركزية
│   └── theme_provider.dart
├── screens/
│   ├── app_shell.dart     # Sidebar + تنقل
│   ├── dashboard_screen.dart
│   ├── students_screen.dart
│   ├── attendance_screen.dart
│   ├── payments_screen.dart
│   └── exams_screen.dart
├── widgets/               # مكونات مشتركة
└── theme/
    └── app_theme.dart     # ألوان وخطوط
```
